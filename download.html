⚠ বিটা সংস্করণ

Nova AI এখনো বিটা। ফোন নিয়ন্ত্রণের কাজ (অ্যাপ চালানো, মেসেজ পাঠানো) স্ক্রিন পড়ে করা হয়, তাই মাঝে মাঝে ভুল বা দেরি হতে পারে। গুরুত্বপূর্ণ মেসেজ পাঠানোর পর একবার চেক করে নিন। কোনো সমস্যা পেলে নিচের ঠিকানায় জানান।

ইনস্টলের ধাপ

  1. উপরের Download APK চাপুন এবং ফাইলটি নামান।
  2. ফাইলটি খুলুন। ফোন "অজানা উৎস থেকে ইনস্টল" অনুমতি চাইলে Settings খুলে এই ব্রাউজারের জন্য অনুমতি দিন, তারপর ফিরে এসে Install চাপুন।
  3. অ্যাপ খুলে Gmail বা ইমেইল দিয়ে লগইন করুন।
  4. Settings → Connections-এ আপনার নিজের Gemini API key দিন (ফ্রি key: Google AI Studio থেকে)।
  5. মাইক্রোফোনের অনুমতি দিন।

ফোন নিয়ন্ত্রণ চালু করতে (ঐচ্ছিক)

  1. ফোনের Settings → Accessibility → Installed apps (বা Downloaded apps) → Nova খুলুন।
  2. চালু করুন এবং ফোন যা বলবে সেই সতর্কতায় Allow দিন। কিছু ফোনে "Restricted setting" দেখালে: অ্যাপের তথ্য পাতার ওপরে-ডানের ⋮ চেপে Allow restricted settings দিন।
  3. নোটিফিকেশন পড়ে শোনাতে চাইলে Notification access-এও Nova চালু করুন।

Accessibility দিয়ে Nova শুধু আপনি কাজ দিলে স্ক্রিন পড়ে ও ট্যাপ করে। পাসওয়ার্ড ঘর পড়া হয় না। বিস্তারিত গোপনীয়তা নীতিতে।

নিরাপত্তা

  • APK শুধু এই পাতা থেকে নামান। অন্য কারও কাছ থেকে পাওয়া ফাইল ইনস্টল করবেন না।
  • আপনার API key শুধু আপনার ফোনে এনক্রিপ্ট করে থাকে।

⚠ Beta version

Nova AI is still in beta. Phone-control tasks (opening apps, sending messages) work by reading the screen, so sometimes they may be slow or wrong. Check important messages after sending. If you find a problem, tell us using the contact below.

Install steps

  1. Tap Download APK above and download the file.
  2. Open the file. If the phone asks for "install unknown apps" permission, open Settings, allow it for this browser, come back and tap Install.
  3. Open the app and sign in with Google or email.
  4. Go to Settings → Connections and add your own Gemini API key (a free key from Google AI Studio).
  5. Allow the microphone permission.

Turn on phone control (optional)

  1. Open phone Settings → Accessibility → Installed apps (or Downloaded apps) → Nova.
  2. Turn it on and tap Allow on the warning. If the phone shows "Restricted setting": open the app info page, tap ⋮ at the top right, then Allow restricted settings.
  3. To let Nova read notifications aloud, also turn Nova on in Notification access.

With Accessibility, Nova reads the screen and taps only when you give it a task. Password fields are not read. See the privacy policy for details.

Safety

  • Your API key stays encrypted on your phone only.
